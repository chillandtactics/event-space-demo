# Пространство для событий

Статическая демонстрационная страница для вымышленной площадки событий. Пакет рассчитан на размещение как обычный статический сайт.

## Что есть в демо

- три визуальные темы, меню, выбор формата и пространства;
- галерея атмосферы и блюд, FAQ и адаптивная компоновка;
- двухшаговая демонстрационная форма: данные не отправляются и не сохраняются.

Для поисковых систем задано `noindex,nofollow`. Все изображения в пакете сгенерированы для вымышленной концепции; они не описывают реальную площадку. В комплекте используется локальный шрифт Manrope Variable и его лицензия [SIL Open Font License 1.1](assets/Manrope-OFL.txt).

Откройте `index.html` в статическом хостинге или через локальный HTTP-сервер.
