# Пространство для событий

Демонстрационный сайт для свадеб, корпоративов и частных праздников без привязки к реальной площадке.

Светлая, тёмная и шоколадная темы, адаптивная компоновка, выбор пространства, галерея и FAQ. Форма демонстрационная: заявки и контактные данные не отправляются и не сохраняются.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root).

Сайт статический: сборка и сервер не требуются. Файлы index.html, styles.css, app.js и assets публикуются вместе. Все ссылки на ресурсы относительные.

## Изменения

Тексты: index.html. Темы и компоновка: styles.css. Интерактивные элементы и описания залов: app.js. Изображения: assets/.

Изображения иллюстрируют вымышленное пространство. Часть создана для прототипа, часть взята из предоставленных материалов. Лицензия на повторное использование сторонних материалов этим репозиторием не предоставляется.
